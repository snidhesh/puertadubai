# Brand assets — placeholders

`logo.png` and `logo-black.png` were dropped into the repo as PNG placeholders. They
are NOT approved brand assets for production use.

Before launch:
1. Request the original vector files (Adobe Illustrator, Figma, or Sketch source) from
   the brand owner.
2. Export to optimised SVG (SVGO with `removeViewBox: false`).
3. Place at `public/brand/logo.svg` (full lockup) and `public/brand/logo-mark.svg`
   (mark-only for nav + favicon).
4. Delete the PNG files once SVGs are committed.
5. Tracing the PNGs is a last resort and requires brand-owner approval.

See `docs/asset-audit.md` for the full asset audit checklist.
